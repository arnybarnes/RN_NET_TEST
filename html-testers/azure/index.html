React Native App

The mobile client is an Expo / React Native app called RN Task Console. It talks directly to the deployed Azure Functions endpoint and exercises the task API from a phone.

The app uses bottom tabs for Connect, Create, and List. This web version keeps the same task workflow but moves navigation to top tabs for browser use.

Connect holds the API base URL, a health check, and a task count action. Create posts new tasks. List shows editable task cards with status, save, delete, and timestamp controls.

Run it

cd mobile
npm install
